This shader is a high-fidelity NTSC signal simulation designed 
to bring authentic 90s nostalgia to your modern Godot projects.

------------------------------------------------------------
QUICK SETUP GUIDE:
------------------------------------------------------------
1. Create a "CanvasLayer" or "ColorRect" covering your screen.
2. In the Inspector, create a new "ShaderMaterial".
3. Drag and drop "RetroVision_Pro.gdshader" into the Shader slot.
4. Ensure the texture "Filter" mode is set to "Linear" for 
   accurate Chroma Bleeding effects.

------------------------------------------------------------
PRO TIPS FOR BEST LOOK:
------------------------------------------------------------
* BLEED AMOUNT: Set this to 1.7 for classic NTSC "waterfall" 
  transparency.
* SCANLINE COUNT: For a "Pixel-Perfect" look, set this to 
  match your game's vertical resolution (e.g., 224, 240, or 448).
* BRIGHTNESS/CONTRAST: Use these to compensate for the slight 
  darkening caused by scanlines.
